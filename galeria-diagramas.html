⏱️ 6. Diagrama de Secuencia Operativa End-to-End

Línea temporal detallada de eventos entre el proveedor, el bot de ingesta, la API Kipintoch y el operador.

sequenceDiagram
    autonumber
    actor P as 🏢 Proveedor
    participant E as 📧 Email (Listener)
    participant IA as 🤖 Motor OCR / IA
    participant BOT as ⚙️ Orquestador Backend
    participant API as 🌐 API Kipintoch
    actor OP as 👤 Operador ALMAR
    participant KIP as 💻 Kipintoch (DB)

    P->>E: Envía factura PDF por email
    E->>BOT: Listener detecta nuevo email
    BOT->>IA: Envía PDF para extracción
    IA-->>BOT: Devuelve JSON estructurado
    BOT->>API: GET /forwarding/carpetas (busca HBL)
    API-->>BOT: Carpeta encontrada (ID: 1435)
    BOT->>API: GET /empresas (valida CUIT)
    API-->>BOT: Proveedor validado (ID: 1247)
    BOT->>API: GET /configuracion/gastos
    API-->>BOT: Gasto clasificado (FMA)
    BOT->>OP: Notifica comprobante en Dashboard
    OP->>OP: Revisa datos lado a lado
    OP->>BOT: Click en "Aprobar"
    BOT->>API: POST Carga costo de compra
    BOT->>API: POST Adjunta PDF original
    API->>KIP: Actualiza Cierre Contable ✅
