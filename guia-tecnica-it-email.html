🛠️ Instructivo Técnico para Administrador de IT

Habilitación de permisos de lectura de correos para el Bot de Ingesta Automática de Facturas (ALMAR Rosario).

🔵 Opción A: Microsoft 365 / Azure Active Directory (Recomendado)

Paso a paso para el administrador con rol Global Admin en Microsoft 365:

  1. Ingresar al portal de administración de Azure: portal.azure.com.
  2. Ir a Microsoft Entra ID (Azure AD) ➔ App Registrations (Registro de aplicaciones) ➔ Nuevo registro.
  3. Nombrar la aplicación: ALMAR-Bot-Facturas y seleccionar "Solo cuentas de este directorio organizativo".
  4. En el menú lateral, ir a API Permissions (Permisos de API) ➔ Agregar un permiso ➔ Microsoft Graph ➔ Application Permissions (Permisos de aplicación).
  5. Buscar y marcar el permiso: Mail.Read (Lectura de correos).
  6. Hacer clic en el botón "Conceder consentimiento de administrador para ALMAR" (Grant Admin Consent).
  7. Ir a Certificates & Secrets (Certificados y secretos) ➔ Nuevo secreto de cliente. Copiar el valor generado (Client Secret).
📋 Datos a entregar al equipo de desarrollo:
Tenant ID: [Copiar del panel General/Overview de la App] Client ID: [Copiar del panel General/Overview de la App] Client Secret: [Valor generado en la pestaña Certificados y Secretos] Casillas: [Lista de mails corporativos a monitorear]

🟡 Opción B: Google Workspace (Cuenta de Servicio)

Paso a paso para el administrador de Google Workspace:

  1. Ingresar a la consola de Google Cloud: console.cloud.google.com.
  2. Crear un proyecto denominado ALMAR-Bot-Facturas.
  3. Ir a IAM y Administración ➔ Cuentas de Servicio ➔ Crear Cuenta de Servicio.
  4. Habilitar la Delegación de autoridad en todo el dominio (Domain-Wide Delegation).
  5. En la pestaña Claves, hacer clic en Agregar Clave ➔ Crear clave nueva (JSON).
  6. En la Consola de Administración de Google Workspace (admin.google.com), ir a Seguridad ➔ Controles de API ➔ Delegación en todo el dominio y agregar el Client ID con el Scope: https://www.googleapis.com/auth/gmail.readonly.
📋 Datos a entregar al equipo de desarrollo:
Archivo JSON: [service-account-key.json descargado] Casillas: [Lista de mails corporativos a monitorear]

🟢 Opción C: Contraseña de Aplicación / IMAP (Alternativa Rápida)

Ideal para pruebas rápidas o casillas dedicadas sin configuración de Azure/Google Cloud:

  1. Definir la casilla de recepción (ej: facturas@almarrosario.com).
  2. En la configuración de seguridad de la cuenta de mail, activar la Verificación en 2 pasos.
  3. Generar una Contraseña de Aplicación (App Password) de 16 caracteres.
  4. Entregar la dirección de mail y la Contraseña de Aplicación de 16 caracteres.
