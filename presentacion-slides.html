🚀 Automatización de Carga de Facturas

Proyecto de Apoyo: Administración, Facturación y Finanzas — ALMAR Rosario

01 / 09
Objetivo de esta Presentación: Validar el proceso real de recepción y carga de facturas de proveedores (costos de compra) para acordar la arquitectura final de automatización e iniciar el desarrollo sin bloqueos.

🔴 El Problema Actual

  • Recepción dispersa en correos personales de operadores.
  • Tipeo manual repetitivo (10 a 15 minutos por comprobante).
  • Matcheo manual de carpeta por carpeta.
  • Sin trazabilidad previa para auditoría ISO 9001:2015.

🟢 La Solución Propuesta

  • Ingesta Automática: Captura de facturas desde correos.
  • Extracción Inteligente: OCR + IA para lectura de PDFs.
  • Dashboard 1-Clic: Revisión asistida con principio Human-in-the-Loop.
  • Carga en Kipintoch: Inyección directa via API con adjunto.
Principio Rector: El bot realiza el 90% del trabajo pesado (lectura y matcheo), pero el operador conserva el control final de aprobación.

🛠️ Manejo de Correos Descentralizados

3 alternativas para no alterar la rutina del personal de ALMAR

04 / 09

Opción A: Regla M365

Cero Cambio Operativo. Regla transparente en M365 reenvía una copia del PDF entrante al bot. El empleado no cambia nada.

Opción B: Graph API (Recomendada)

Listener Transparente. El bot monitorea las casillas corporativas via MS Graph API en segundo plano. Filtrado automático sin reenvíos.

Opción C: Reenvío Asistido

1 Clic Manual. El operador da 'Reenviar' a facturas@almar.com y el bot devuelve la orden lista en el Dashboard.

Conclusión Técnica: Las Opciones A y B eliminan cualquier resistencia del personal ya que no exigen cambiar cuentas de correo ni acuerdos comerciales con proveedores.

⚠️ Resolución de Casos de Borde (Edge Cases)

Mecanismos de contingencia para facturas complejas o atípicas

07 / 09
Caso de Borde Escenario Real Solución de la Arquitectura
1. Sin HBL / Booking Fletes de camión local que no traen referencias de ALMAR. Búsqueda Heurística: Busca por CUIT + Contenedor + Fechas (±5 días). Si hay dudas, sugiere 2 carpetas candidatas.
2. Proveedor Nuevo Factura de un proveedor inédito no cargado en Kipintoch. Pre-alta Asistida: El OCR extrae datos fiscales y ofrece el botón "Dar de Alta Proveedor y Aprobar" (POST /empresas/guardar).
3. Multi-Ítem / Split Facturas de Maersk/MSC con Flete + THC + BL Fee. Desglose Inteligente: Separa renglón por renglón y memoriza homologaciones de conceptos nuevos.
